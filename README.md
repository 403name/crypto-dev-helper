# Crypto Dev Helper

A Cursor/Claude Code skill for Web3 and cryptocurrency development. Provides best practices for wallet integration, smart contract deployment, DeFi protocols, and trading bot development.

## Installation

```bash
# Via skills.sh
skills install blockchain-utility/crypto-dev-helper

# Via reskill
reskill install blockchain-utility/crypto-dev-helper

# Manual
git clone https://github.com/blockchain-utility/crypto-dev-helper.git
cp -r crypto-dev-helper/.cursor/skills/crypto-dev-helper .cursor/skills/
```

## What it does

- Suggests appropriate npm packages for blockchain tasks
- Provides code patterns for wallet connectivity, contract deployment, token operations
- Guides on best practices for crypto/Web3 development

## Auto-discovery

Cursor and Claude Code automatically discover this skill when working with blockchain-related files.
